# Level 0 – Foundations

Level 0 is designed for absolute beginners. It focuses on programming fundamentals like input/output, conditions, loops, arrays, strings, and basic math (GCD, primes, LCM). You'll also get an introduction to brute force and greedy algorithms, and you'll begin to analyze time complexity. This level is all about building confidence and fluency with simple problems — it’s where you get comfortable writing clean, fast code.
