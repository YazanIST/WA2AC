# Level 2 – Intermediate Concepts

In Level 2, you tackle more complex algorithms and patterns. You'll learn shortest path algorithms (Dijkstra, Bellman-Ford, Floyd-Warshall), Disjoint Set Union (DSU), and Minimum Spanning Trees (Kruskal and Prim). You'll dive deeper into dynamic programming, and cover tree fundamentals, modular arithmetic, Fermat's theorem, and combinatorics.
